# MiSmartPenX

一个简约、精美的安卓组件，专为小米平板设计，用于在屏幕顶部实时显示小米触控笔的电量。

## 功能特点

- **自动感应**：当触控笔连接时自动弹出电量胶囊，断开时自动消失。
- **精美设计**：采用玻璃拟态设计风格，支持充电状态显示。
- **极简体验**：无广告、无后台多余操作，仅在需要时出现。
- **快捷控制**：支持通过下拉通知栏快速开启或关闭悬浮窗。

## 安装说明

1. 下载并安装最新的 APK 文件。
2. 打开应用，根据提示授予以下权限：
   - **显示在其他应用上层**（悬浮窗权限）：用于在屏幕顶部显示电量胶囊。
   - **通知权限**：用于保持后台监控服务运行。
3. 权限授予后，应用将自动开始工作。

## 常见问题

- **为什么电量不更新？**
  请确保已在平板设置中允许该应用“自启动”，并将其“省电策略”设为“无限制”。
- **如何关闭？**
  下拉通知栏点击“隐藏悬浮窗”，或者直接停止该应用。
